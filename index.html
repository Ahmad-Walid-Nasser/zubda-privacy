Zubda

Zubda is a personal study app made by Ahmad Nasser.

Privacy policy

Zubda uploads lecture recordings only to the user's own Google Drive, using the drive.file permission: it can see only the files it creates. Recordings are never shared with anyone else, sold, or used for advertising.

Course data is stored in the user's own account and is not shared.
